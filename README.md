## 👨‍💻 About Me

I am a passionate Software Engineer from India, working in the Defence Manufacturing Industry with a strong focus on Embedded Systems, Industrial Networking, Real-Time Software Development, and Hardware-Software Integration.

I enjoy designing, developing, testing, and debugging reliable software solutions that connect hardware devices, communication networks, and intelligent applications.

- 🔭 Currently working on embedded software and industrial system integration.
- 🌱 Continuously learning advanced C++, embedded Linux, system architecture, and real-time software development.
- 💻 Experienced in C, C++, Python, and Java.
- ⚙️ Interested in microcontrollers, communication protocols, sensor integration, and automation.
- 🖥️ Developing cross-platform applications for Windows and Linux.
- 📡 Working with Ethernet, CAN, UART, TCP/IP, UDP, and multicast communication.
- 🎯 Focused on building reliable, scalable, maintainable, and high-performance software.
- 🤝 Open to technical collaboration and open-source contributions.
- 📍 Maharashtra, India.
